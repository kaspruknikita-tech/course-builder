# Источники поля

Где практики обсуждают тему курса. Процедура — скилл, `references/field.md`. Сборщик `scripts/field.py` читает эту таблицу: колонки «Тип» и «Адрес» обязательны, строки со статусом «выбыл…» пропускаются.

**Тип:** `telegram` — имя публичного канала без @; `reddit` — сабреддит без r/; `stackexchange` — сайт или сайт:тег (`ux`, `serverfault:monitoring`); `hn` — поисковый запрос к Hacker News; `rss` — адрес ленты; `поиск` — запрос вроде `site:vc.ru <тема> кейс`, его читает Claude, а не скрипт.
**Статус:** новый, живой, выбыл: <причина>.
