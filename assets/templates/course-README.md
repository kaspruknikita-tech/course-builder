# {{TITLE}}

Твой курс, собранный под тебя скиллом [course-builder](https://github.com/kaspruknikita-tech/course-builder).

## Как учиться

1. Открой Claude Code в этой папке:

   ```bash
   cd "{{PATH}}" && claude
   ```

2. Напиши «урок». Claude начнёт с повторов, потом теория, практика и разбор.
3. В любой момент напиши «где я» — получишь одно следующее действие.

## Команды

| Напиши | Что будет |
|---|---|
| урок | следующий урок: повторы → попытка → теория → практика → разбор → припоминание |
| упражнение | тренировка процедуры на новом кейсе, поддержка с каждым разом меньше |
| застрял | подсказка — по одной ступени, без готового ответа |
| сдаю | проверка работы модуля по чек-листу |
| защита | защита работы перед комиссией из героев кейса |
| повтор | только вопросы на повтор |
| тест | отложенный тест без конспектов и AI |
| прогресс | цифры: модули, повторы, подсказки, тесты |
| обнови поле | свежие ситуации и вопросы практиков из сообществ по теме — раз в месяц |
| ретро | разбор курса по цифрам: что работает, что заменить |
| отзыв | сообщить автору скилла о проблеме — черновик issue, публикация только после твоего «да» |
| поменять программу | правка программы, решаешь ты |
| где я | одно следующее действие |

## Что где лежит

| Папка | Что |
|---|---|
| `lessons/` | уроки по модулям |
| `work/` | твои работы по модулям и учебные данные |
| `materials/` | файлы источников: PDF, конспекты |
| `_course/` | служебное: программа, кейс, источники, прогресс |
| `_course/field/` | поле: сообщества практиков по теме и банк живых ситуаций |

**Не открывай** `_course/case-hidden.md`, `_course/drills.md` и `_course/keys/`. Там скрытые факты кейса и эталоны: увидишь их заранее — упражнения потеряют смысл, ведь добывать факты вопросами и есть навык.

## Почему курс устроен так

- Попытка до теории: объяснение лучше ложится на вопрос, который ты уже себе задал.
- Подсказки вместо ответов: AI, который решает за тебя, делает тебя слабее там, где AI рядом не будет.
- Повторы через растущие интервалы и тест через недели: проверяется память, а не ощущение «понял».
