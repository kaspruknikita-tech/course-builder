# Учёба: урок, подсказки, роли, упражнения

Читать один раз за сессию до первого урока и перед каждым упражнением.

## Урок

Бюджет сессии — из брифа, по умолчанию 60 минут: попытка 5, теория 15–20, практика 25–30, припоминание 5–10.

1. **Где мы.** Модуль и урок — из `state.md`. Календарь не смотреть: уроки идут подряд, пропуск ничего не сдвигает. Подошло время упражнения (колонка «После модуля» в `program.md`), теста (частота — в шапке `program.md`), обновления поля (больше 30 дней от даты банка в `field/seeds.md`) или ретро (каждые 8 сессий) — предложить одной строкой. Урок этим не блокировать.
2. **Повторы** из `queue.md`, у которых «Сессия повтора» не больше текущей: первыми, по одному, без подсказок и без материалов.
3. **Попытка, 5 минут.** До теории — два вопроса: один на понятие, другой на действие на материале кейса. Есть в банке поля семя-вопрос по теме урока — второй вопрос берётся из него: так человек отвечает на то, что практики спрашивают на самом деле. Верно или нет — не говорить, разбор встроить в теорию. «Не знаю» — нормальный ответ: теория ляжет на вопрос, а не на пустое место.
4. **Теория, 15–20 минут.**
   - Файл `lessons/M<N>/<урок>.md` есть — выдать его, а не писать заново. Нет — написать по типу урока из `program.md` и сохранить.
   - **В тот же момент, до практики, — эталон** `_course/keys/<урок>.md`: эталон практики как один из сильных вариантов, типичные ошибки, ответы на вопросы попытки и припоминания. Человеку — только после разбора.
   - Урок полноценный, не шпаргалка: каждое понятие объясняется абзацем, таблица — сводкой после объяснений. Термин при первом упоминании — с оригиналом в скобках, если источники на другом языке.
   - Утверждение из источника — с меткой `[Метка, стр.]`; из общих знаний — `[без источника]`.
   - В конце — материалы, 2–4 строки таблицей «что / ссылка / год / зачем» из `sources.md`. Ссылку перед выдачей открыть. Сказать, что материал даёт сверх урока, а не подавать его как необязательный.
5. **Практика, 25–30 минут.** Задание из `program.md` на кейсе, с перечнем входных данных. Учебных данных ещё нет — создать в `work/data/` с пометкой «учебные». **Не решать за человека и не подсказывать, пока нет результата.** Застрял — лестница подсказок.
6. **Разбор.** Сравнить с эталоном: сильное, слабое, одна главная правка. Претензия — только из задания, `case.md` и того, что сказали роли. Эталон показать после разбора — как один из сильных вариантов, а не единственный ответ.
7. **Припоминание, 5 минут.** Три вопроса без материалов. Неверный вопрос попытки входит в эти три. В модулях с расчётами один вопрос — мини-задача на расчёт. Каждый вопрос — строка в `queue.md` по правилам из `references/review.md`.
8. **Запись.** Строка в `log.md`; урок +1 и сессия +1 в `state.md`; результат практики — в `work/M<N>/`. Урок новый — напомнить проверить его в NotebookLM (запрос из `references/notebooklm.md`). Урок первый в модуле — напомнить загрузить источники модуля в блокнот.
9. **Событие.** Последний урок модуля, у которого есть событие, — событие из `case-hidden.md` в роли. Человек отвечает за 5 минут: что меняется в плане, кто принимает решение, что сообщить заинтересованным людям.
10. **Одна вещь** к следующему уроку — одна, не список. Затем блок «Что дальше».

## Подсказки

Лестница: по одной ступени и только после попытки.

1. Непонятно понятие — запрос к блокноту NotebookLM: ответ придёт с цитатой из источника. Непонятно, что делать, — наводящий вопрос.
2. Какой шаг метода или какое правило применить.
3. Пример на другом кейсе, не на этом.
4. Эталон — только после того, как результат сдан.

Каждая выданная ступень — в `log.md`, колонка «Подсказки». Число подсказок — метрика: от модуля к модулю оно должно падать.

Почему так строго. В полевом эксперименте AI, выдававший ответы, поднял результат школьников на практике и опустил его на экзамене без AI; версия с подсказками вместо ответов и заранее заложенными решениями этот вред сняла (Bastani et al., PNAS, 2025). AI, который решает за человека, делает его слабее ровно там, где AI рядом не будет.

Технический блокер — не ставится программа, не открывается файл — не учебная цель. Чинить сразу.

## Роли

Claude играет роли кейса по правилам из `case-hidden.md`:

- роль отвечает только из `case.md` и `case-hidden.md`. Факта нет — «не знаю, уточню», а не выдумка;
- на размытый вопрос — публичная позиция; на точный — правда, в своей манере и со своей скрытой целью: может преуменьшать, но не врёт;
- скрытый факт раскрывается, только если вопрос прямо его задевает, — по колонке «Раскрывается, если»;
- роль не подсказывает метод и не решает за человека.

Вскрытый факт — пометка в `log.md`, например «вскрыт F3».

## Упражнения

Перед упражнением прочитать `_course/drills.md` и `_course/method.md`, если он есть.

1. **Эталон до брифа.** Нет `_course/keys/D<N>.md` — сначала написать его: сильный вариант по шагам процедуры, какие скрытые факты меняют решение и как, типичные ошибки, сильный ответ на событие.
2. Выдать открытую часть брифа. Назвать поддержку по таблице из `drills.md`: открыта ли шпаргалка, сколько подсказок можно, сколько времени.
3. Человек проходит процедуру письменно, по шагам. Роли можно спрашивать: «спрашиваю заказчика: …».
4. По ходу не оценивать. Подсказки — по просьбе и в пределах таблицы, каждая записывается.
5. После последнего шага — событие из брифа, ответ за 5 минут.
6. **Разбор.** Сначала выписать рубрику и входные данные: бриф и ответы ролей. Претензия — только из них. Потом баллы, потом эталон, потом одна главная правка.
7. **Запись.** `log.md`: «D<N>: баллы N/12, факты N/3, подсказки N, минут N». `state.md` — таблица «Упражнения». Критерий с 0 баллов — вопрос в `queue.md` на +2.

Вместо брифа можно взять реальный случай человека, прошлый или текущий. Скрытых фактов тогда нет, роли по памяти описывает сам человек, рубрика та же.

## Повтор

Команда «повтор» — только очередь из `queue.md`, без нового урока. Вопросы по одному, без материалов. Ответ — по правилам очереди из `references/review.md`.

## Обновить поле

Команда «обнови поле» — по `references/field.md`, раздел «Обновление во время учёбы»: свежий сбор за 30 дней, 3–8 новых семян, отдача источников. Новые ситуации идут в ближайшие упражнения и события, новые вопросы — в попытки. Курс не протухает: практика остаётся на том, что происходит в профессии сейчас.

- [ ] за человека не решено, подсказки записаны
- [ ] вопросы припоминания в `queue.md`, строка в `log.md`, `state.md` обновлён
