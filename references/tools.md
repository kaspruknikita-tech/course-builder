# Этап 0. Старт и инструменты

Читать до этапа 0 и всякий раз, когда человек спрашивает, что поставить.

Цель этапа: узнать тему, создать папку курса и до интервью выяснить, чем будем искать источники. Недостающее — поставить сразу. MCP-серверы подключаются только при запуске Claude Code, поэтому ставить их нужно в начале: после установки — перезапуск, и сборка продолжится с интервью.

Маркеры у команд: **[проверено]** — команда выполнялась, сервер подключился; **[по документации]** — взято из документации производителя, вживую не запускалось. Пользуешься пунктом «по документации» — скажи человеку, что получилось: это повод открыть issue и уточнить инструкцию.

## 1. Тема и папка

1. Тема одной фразой, если её не было в первом сообщении. Остальное спросит интервью.
2. Где хранить курс. По умолчанию — `~/courses/<короткое-имя>/` (на Windows — `%USERPROFILE%\courses\<имя>`). Имя латиницей через дефис: `ux-research`, `sql-basics`.
3. Создать папку:

   ```bash
   python3 <путь к скиллу>/scripts/scaffold.py ~/courses/ux-research --title "UX-исследования" --lang ru
   ```

   Скрипт создаёт структуру, служебные файлы из `assets/templates/` и строку в реестре `~/.course-builder/courses.md`. Папка уже есть — скрипт откажется её трогать: спросить человека, продолжать ли старый курс.
4. Сказать, что дальше удобнее открывать Claude Code прямо в папке курса: `cd ~/courses/ux-research && claude`. Тамошний `CLAUDE.md` сам напомнит, что это курс.

## 2. Что уже есть

Посмотреть на список своих инструментов и найти:

| В названии инструмента | Что это | Зачем курсу |
|---|---|---|
| `WebSearch`, `WebFetch` | встроенный поиск и чтение страниц | базовый поиск источников |
| `exa` | Exa — поиск по смыслу | хорошо находит первоисточники, исследования, документацию |
| `firecrawl` | Firecrawl — поиск и чтение страниц | читает длинные страницы и PDF, где обычное чтение обрезается |
| `context7` | Context7 — документация библиотек | уроки по коду на актуальной версии, а не по памяти модели |
| `playwright` | управляемый браузер | разбор живых сайтов: скриншоты, сценарии, доступность |
| `figma` | Figma | практика на настоящих макетах |

**Наличие в списке — ещё не работа.** Каждым поисковым инструментом сделать один пробный запрос по теме курса и убедиться, что пришли результаты. Ошибка, пусто или «лимит исчерпан» — считать инструмент отсутствующим. Запасной путь проверяется так же, как основной, иначе один отказ маскирует другой.

## 3. Что предложить поставить

### Поиск — по желанию, с ключами

Два дополнительных поисковика со своими индексами. Firecrawl, кроме поиска, читает длинные страницы и PDF, которые встроенное чтение обрезает. Без них курс соберётся на встроенном поиске; насколько с ними лучше, никто не измерял — не обещать человеку «больше хороших источников». Оба подключаются без ключа **[проверено]**, но без ключа лимит очень маленький: Exa при подготовке этого скилла кончился после трёх запросов, а курсу нужно 30–40. Поэтому предлагать сразу с ключами, а вариант без ключа — только чтобы попробовать:

```bash
claude mcp add --scope user --transport http exa https://mcp.exa.ai/mcp
claude mcp add --scope user --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp
```

`--scope user` — сервер будет доступен во всех папках, а не только в текущей.

### Ключи — нужны для сборки курса

Без ключа лимит кончится посреди этапа 2, и инструмент вернёт ошибку про лимит. Бесплатный ключ решает это, получить его — пара минут.

| Сервис | Где взять ключ | Как передаётся |
|---|---|---|
| Exa | зарегистрироваться на exa.ai, ключ на странице `dashboard.exa.ai/api-keys` | заголовок `x-api-key` |
| Firecrawl | зарегистрироваться на firecrawl.dev, ключ в личном кабинете, раздел API Keys | заголовок `Authorization: Bearer` |

Если сервер уже добавлен без ключа — сначала удалить его, потом добавить с ключом **[проверено]**:

```bash
claude mcp remove exa -s user
claude mcp add --scope user --transport http exa https://mcp.exa.ai/mcp --header "x-api-key: ТВОЙ_КЛЮЧ"

claude mcp remove firecrawl -s user
claude mcp add --scope user --transport http firecrawl https://mcp.firecrawl.dev/v2/mcp --header "Authorization: Bearer ТВОЙ_КЛЮЧ"
```

**Безопасность ключа — сказать человеку прямо:**

- Ключ — как пароль. Команду с ключом человек выполняет **сам, в своём терминале**, а не присылает ключ в чат: всё, что вставлено в чат, остаётся в истории переписки.
- Claude Code хранит ключ открытым текстом в `~/.claude.json`. Этот файл нельзя публиковать и коммитить.
- Ключ утёк — отозвать его в кабинете сервиса и создать новый.
- «✓ Connected» в `claude mcp list` не доказывает, что ключ верный: ключ проверяется при первом запросе. После перезапуска — пробный поиск.

### По теме курса — предлагать, только если тема подходит

| Тема | Сервер | Команда | Зачем | Маркер |
|---|---|---|---|---|
| Программирование, инструменты разработки | Context7 | `claude mcp add --scope user --transport http context7 https://mcp.context7.com/mcp` | документация нужной версии библиотеки | [проверено] |
| UX, UI, веб, доступность | Playwright | `claude mcp add --scope user playwright -- npx @playwright/mcp@latest` | открывать живые сайты, снимать экраны, проходить сценарии; нужен Node.js | [проверено] |
| Дизайн интерфейсов | Figma | `claude plugin install figma@claude-plugins-official`, затем `/plugin` → figma → вход в аккаунт | читать и править свои макеты; на бесплатном тарифе Figma лимит запросов низкий | [по документации] |

### Скилл глубокого исследования — по желанию

Метод этапа 2 самодостаточен, отдельный скилл не нужен. Если у человека уже стоит скилл исследований, его можно взять для поиска. Таблицу источников, уровни доверия и проверку ссылок всё равно ведёт этот скилл по `references/research.md`. Пример такого скилла **[по документации]**:

```bash
git clone https://github.com/199-biotechnologies/claude-deep-research-skill.git ~/.claude/skills/deep-research
```

Перед тем как полагаться на него, проверить, что он работает с языком курса.

## 4. Как предложить

1. Показать таблицу: что есть, чего нет и что конкретно даст каждый инструмент (по таблице раздела 2). Не обещать «больше источников» без измерения: курс соберётся и без MCP, на встроенном поиске.
2. Предложить два пути:
   - Человек заводит ключи и сам выполняет команды с ключами в терминале — основной путь.
   - Хочет просто попробовать — можно поставить без ключа (Claude может выполнить сам, если разрешено), но честно предупредить, что лимит кончится за несколько запросов.
3. После установки:

   ```
   ━━ Этап 0 из 4 · Инструменты ━━
   Готово: поставлены exa и firecrawl
   Твой ход: перезапусти Claude Code — /exit, потом в терминале: cd ~/courses/ux-research && claude
   Потом напиши: /course-builder
   ```

4. После перезапуска — пробный поиск каждым новым инструментом, затем интервью.
